# Code of conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).

In issues, pull requests and anywhere else this project is discussed:

- Be respectful and assume good intent.
- Keep criticism about the work, not the person.
- No harassment, personal attacks, discrimination, or sharing other people's private information.
- Do not ask for or share copies of game software.

The maintainer may edit or remove comments, close threads, or block accounts that break these rules. To report a problem, open an issue titled "Conduct report" with no details, and you will be given a private way to send them.
