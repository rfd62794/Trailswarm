# Security policy

Only the current `main` branch is supported.

Please do not report a security problem in a public issue. Use GitHub's private reporting: open the **Security** tab and choose **Report a vulnerability**. If that option is not shown, open an issue titled "Security contact request" with no details, and you will be given a private way to send them.

This is a one-person project, so there is no fixed response time. Reports are read, confirmed or declined, and fixed in order of impact.

The MCP server (`uv run pokeagent mcp`) and the agent control API are meant for local use on your own machine. Do not expose them to a network.
