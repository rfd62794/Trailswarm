## 1. Why this exists

Robert and the agents keep re-learning the same world. Settled with Robert 2026-11-02: three layers.
**Layer 1** `runs/<ts>/transitions.jsonl` is raw and append-only, one line per press:
`{"step","from":[map,x,y],"button","to":[map,x,y],"moved","textbox","text","facing","source"}` (the explorer demo
`tools/explore_demo.py` writes all of these). **Layer 2** `runs/maps.json` is agent memory (gitignored, written by
`MapMemory`): `{"maps": {"<id>": {"visited": {"x,y": n}, "blocked": ["x,y,DIR"], "warps": {"x,y,DIR": [map,x,y,taken?]},
"interactions": {"x,y,DIR": {"count","text","presses":[..],"menus":[..],"choices":[..]}}, "last_seen"}}, "updated"}`.
**Layer 3** `kb/world.json` is this directive: a deterministic, committed, human-reviewable compile of layers 1+2 plus
human seeds. Verified facts you build on (`docs/KNOWLEDGE.md`): `0xD31D` bag count (0->1 on withdrawing the POTION),
`0xD53A` PC box count, `0xD347` money (3 bytes BCD), `0xD35E` map, `0xD361/0xD362` y/x; map `0x26` REDS_HOUSE_2F,
`0x25` REDS_HOUSE_1F, `0x00` PALLET_TOWN; the PC menu has WITHDRAW ITEM. `0xD163` party and `0xD057` battle are
UNVERIFIED: never classify from them. Test command `uv run pytest -q` (Python 3.12). No ROM, window or new dependency.

## 3. The work

**`ram_diff` capture.** `transitions.py` gains `class InteractionSnapshot` with `open(emu)` (copies `0xD000-0xD8FF`, so the event-flag range below is covered)
and `close(emu) -> list[list[int]]` (changed bytes `[[addr, old, new], ...]`, ascending addr, first 64 only). `Agent`
calls `open` on the step where an A press takes the text box from none to open, and on the step where the box goes
from open to closed calls `close` and adds `"ram_diff"` to that step's record (other records omit the key). Needs
`pokeagent.textbox`; without it there is no `ram_diff` and the compiler still works. If `tools/explore_demo.py` is
in your worktree, make the same change; if not, note it in the Report.

**`data/pokered_maps.json`**: `{"_status": "reference, unverified except 0x00/0x25/0x26", "maps": {"0": "PALLET_TOWN", ...}}`,
decimal-string ids for 0x00-0x28 only: PALLET_TOWN 0x00, VIRIDIAN_CITY 0x01, PEWTER_CITY 0x02, CERULEAN_CITY 0x03,
LAVENDER_TOWN 0x04, VERMILION_CITY 0x05, CELADON_CITY 0x06, FUCHSIA_CITY 0x07, CINNABAR_ISLAND 0x08, INDIGO_PLATEAU
0x09, SAFFRON_CITY 0x0A, (0x0B omitted), ROUTE_1..ROUTE_25 = 0x0C..0x24 (id-0x0B), REDS_HOUSE_1F 0x25,
REDS_HOUSE_2F 0x26, BLUES_HOUSE 0x27, plus OAKS_LAB 0x28 (observed 2026-11-02).

**Seed block** in `KNOWLEDGE.md`: `{"maps": {"37": {"name": "REDS_HOUSE_1F"}, "38": {"name": "REDS_HOUSE_2F"}, "0":
{"name": "PALLET_TOWN"}}, "warps": [{"from": [38,7,2,"UP"], "to": [37]}, {"from": [37,3,7,"DOWN"], "to": [0]}],
"interactables": [{"map": 38, "x": 0, "y": 2, "dir": "UP", "kind": "pc"}]}` (a seed `to` may be just the map).

**Compile rules** (`kb_compile.compile_world(transitions: list[dict], maps: dict, seed: dict) -> dict`; ids and
addresses are decimal ints in JSON inputs, `"0xD31D"` strings in output; every list sorted, `sort_keys=True`, `indent=1`,
trailing newline, no timestamps):
- `maps[<id>]`: `{id, name, name_source, walkable [[x,y]] (visited), walls [[x,y]] (neighbour tile of each blocked
  edge that is not visited), bounds {min_x,max_x,min_y,max_y} over walkable, exits ["x,y,DIR"] (warps out), first_seen
  (first transitions step whose `to` is this map), last_seen (maps.json)}`. Name: seed (`"human"`) else the pokered
  table (`"inferred"`) else `"MAP_0xNN"`.
- `warps[]`: `{from [map,x,y,DIR], to [map,x,y], taken (4th element, true if absent), return_warp, source}`;
  `return_warp` is the `from` of a known warp that leaves the destination map and lands on this warp's `from` tile, else null.
- `interactables[]`: one per `interactions` key, `{map,x,y,dir,kind,texts[],menus[],choices[],presses_stats {min,max,mean
  (1 decimal)},effects[],raw[],source}`. Effects come from `ram_diff` on the transitions record whose
  `(from, facing)` equals the key. Named deltas: `bag` 0xD31D, `box` 0xD53A, `money` 0xD347-0xD349, `party_count`
  0xD163, `map` 0xD35E, `pos` 0xD361/0xD362, each `{"name","old","new"}`; every other change is kept verbatim as
  `{"addr": "0xD5A3","old","new"}` under `raw`. Nothing is dropped for lacking a name.
- `kind`, first match wins, never guessed: `pc` if any menu contains `WITHDRAW ITEM`; `item` if a `bag` effect has
  `new > old`; `shop` if a `money` effect exists; `sign_or_npc` if there is text; else `silent`.
- `npcs[]`: `{map, at [[x,y,DIR]], texts, moves, reason}`; `reason "same_text"` when one text is seen from two or more
  distinct `(x,y,dir)` on a map; `reason "flaky_edge"` (`moves: true`) when a direction press with `textbox "none"`
  from the same tile and button both moved and did not move in layer 1 (warp edges excluded). `notes.npc_sprites`:
  `"sprite positions live in wSpriteStateData 0xC100-0xC2FF (unverified, a hex-find job)"`.
- `unknown_flags`: `{"0xADDR": {"count", "examples": [[old,new], ...] (max 3)}}` over all `raw` deltas. Noise filter:
  drop an address seen in at least 3 `silent` interactions and at least half of them.
- **Tile types** (`tile_types`, learned per tileset; this lets the agent predict walls on maps it has never visited).
  - Records on direction presses gain optional `"ahead_tiles": [tl,tr,bl,br]` and `"tileset"` (read from `0xD367`
    wCurMapTileset, UNVERIFIED; the compiler keys by `tileset`, else `"map<id>"`). `ahead_tiles` is the 2x2 block of
    wTileMap (`0xC3A0`, 20x18, row-major) in the pressed direction; the player sprite occupies screen cols 8-9, rows 8-9.
    UP = row 6 cols 8-9, DOWN = row 10 cols 8-9, LEFT = row 8 cols 6-7, RIGHT = row 8 cols 10-11 (map tile = 2x2 screen tiles).
  - Output `{"<tileset>": {"0x1A": {"walkable": true|false|null, "seen": n}}}`. A confirmed wall (press, `textbox "none"`,
    not moved, not a warp edge) marks all four ids false; a successful same-map move marks them true; an id with
    both kinds of evidence is `null`. `kb.predict_wall(world, tileset, ahead_tiles) -> bool | None` (False/None never claim a wall).
    `hint` takes optional `ahead: dict[str, list[int]]` and adds `Likely wall: UP` lines.
- **Sprites -> npcs** (all addresses UNVERIFIED, pret/pokered): wSpriteStateData1 `0xC100-0xC1FF` and wSpriteStateData2
  `0xC200-0xC2FF`, 16 sprites x 16 bytes, slot 0 is the player. Data1 +0 picture id, +1 movement status, +9 facing;
  data2 +4 = map Y + 4, +5 = map X + 4.
  - Interaction steps (open and close) gain optional `"sprites": {"pic": [15 ints], "y": [15], "x": [15]}` for slots
    1-15 as raw bytes (the compiler subtracts 4).
  - An NPC is `(map, pic, tile talked to)`; the tile is the faced tile of the interaction, matched to the slot whose
    `(x-4, y-4)` equals it. Output `{map, pic, slot, tile [x,y], texts, moves, reason: "sprite"}`; `moves: true` when
    the same slot's Y/X differ between steps. The text-based inference below is the fallback; a `"same_text"` npc is
    dropped when a `"sprite"` npc covers the same map and texts.
- **Triggers** (`triggers[]`, scripted events; walking onto a tile starts them, no A press): `{id "t<map>_<x>_<y>", where
  [map,x,y], kind "scripted_event", text_seen[], map_after, flags_changed [["0xD747",old,new],..], times_seen, one_time}`.
  - Event step: a record with `textbox "dialog"` or a `ram_diff` entry in `0xD747-0xD886` (wEventFlags bitfield,
    UNVERIFIED) whose `(from, facing)` is not an `interactions` key. `where` is its `from`; `map_after` its `to` map.
  - `one_time` is true when a later step (higher `step`) arrives on `where` with no text, no flag delta and no map change.
  - Every event-flag delta also goes into `unknown_flags` (the noise filter never drops that range).
  - `blocked_by_story`: a tile that was a wall (press not moved) before a trigger's step and entered later is removed
    from `walls` and listed under the map's `conditional_walls: [[x,y,"<trigger id>"]]` (key omitted when empty).
  - `kb show --story` lists triggers ordered by first step seen, with text and `map_after`.
- Seeds win: a seed entity matching by key (map name; warp `from`; interactable `(map,x,y,dir)`) overrides each field
  where both exist, gets `"source": "human"`, and any disagreement is appended to its `"conflicts": [{"field","human","inferred"}]`.
  Everything else is `"source": "inferred"`.

**Merge with the existing file** (`kb.merge(old, new)`): union entities by key; counts and `last_seen` take max,
`first_seen` min, lists union, `presses_stats` min of mins, max of maxes, mean from `new`; `human` source never
downgrades. The file only grows and compiling twice is byte-identical.

**CLI** (`cli.py` only registers; logic in `kb.py`): `pokeagent kb compile [--runs runs] [--maps runs/maps.json]
[--out kb/world.json] [--knowledge docs/KNOWLEDGE.md]` globs `runs/*/transitions.jsonl` (skips bad lines) and prints
a summary: maps, warps, interactables by kind, npcs, unknown flags. `kb show <map_id>` (decimal or `0x26`) prints
`mapmem.render_ascii` over the walkable tiles, overlays `#` walls and a letter on the faced tile of each interactable
(`P` pc, `I` item, `$` shop, `?` sign_or_npc, `o` silent), then lists the map's entities. `kb query "<text>"` prints
entities whose texts, menus or names contain the text, case-insensitive.

**Prompt.** `build_prompt(..., kb_hint: str | None = None)` (keyword, last): when set, add a section
`## Known nearby (knowledge base)` after the map memory; unchanged when `None`. `kb.hint(world, map_id, x, y) -> str` is 3-6
lines: entities within 3 tiles (Chebyshev) with kind and first text, and `Unexplored directions: ...` (neighbours in
neither walkable nor walls). It uses only `"inferred"` records, because `KNOWLEDGE.md` stays out of the prompt. `Agent`
loads `kb/world.json` once if it exists (`--kb PATH`, default `kb/world.json`); the viewer passes the same string when present.
